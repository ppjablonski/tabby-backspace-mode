# Changelog

## 0.1.5
- Backspace key mode (Pass-through, Ctrl-H, Ctrl-?, Delete) for local profiles, on a new **Input** tab
  of the profile editor and in *Advanced > Local terminal* defaults.
- Profiles without an explicit mode inherit the Local terminal defaults, including built-in profiles.
- Verified on Windows, Tabby 1.0.238, WSL / Debian profile with Ctrl-H.

Earlier 0.1.x builds were unpublished iterations.
